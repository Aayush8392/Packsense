# What do people edit each day?

Open Food Facts changes every day. Volunteers add products, correct names, fill in nutrition figures and fix labels. This page counts those edits, so you can see how busy the database is and what kind of work dominates.

Edits are sorted into eight kinds: name and brand, pack size, nutrition, Nutri-Score and NOVA, ingredients, allergens, categories and labels, and other tags. A product is counted as new only when it is on its first revision and did not come from the starting copy.

## What this page can and cannot tell you

- One edit can touch several kinds, so the kinds add up to more than the total. The total is the number to quote.
- OFF's daily file keeps one row per product per day. If a product is edited three times in a day, only one change is seen. All counts are therefore "at least", never "exactly".
- Only whole days are shown, for the same reason as on the quality page.
- An edit is not an improvement. It tells you how much is happening, not whether it helped.
